## 1. 核心循環

開店 → 接客 → 報價／成交 → 打烊 → 夜間生產 → 過夜 → 房租與事件。

- 第 1 天是星期一，七天一輪，房租第 7 天到期。
- 一般顧客名額上限 5（程式寫 6，但所有加成疊滿只到 5）。
- 普通顧客與展示櫃買家是兩套系統，互不佔用名額。

## 3. 價格公式

```
單價 = round( ((max(0, B × (1 + I%)) + C) × max(0, 1 + M%) + L) × F )
實收 = min(單價, 顧客剩餘預算)
```

| 符號 | 名稱 | 內容 | 層內規則 |
|---|---|---|---|
| B | 基礎價值 | 電池類另加剩餘電量折算 | 直接加算 |
| I | 品相層 | 所有品相修正 % 相加 | 同層相加，最低 0 |
| C | 空瓶底價 | 只有液體容器有 | 插在 I 與 M 之間 |
| M | 市場層 | 事件、零售加價、違禁加價、顧客與特權 | 同層相加，與 I 相乘 |
| L | 內含物價值 | 每件內含物各算一次公式後相加 | 不受 I、M 影響，受 F 影響 |
| F | 議價層 | 每項換成 (1 + x%) 後連乘 | ×1.25 與 ×1.2 = ×1.5 |

- 取整：四捨六入，.5 取偶（262.5 → 262，263.5 → 264），最低 0。
- 空瓶底價：450ml 4、750ml 5、2000ml 9、3000ml 25。
- 顧客的臨時市場修正（香水、小費、成癮懲罰、不善議價）會傳給內含物；零售加價與事件加價只按內含物自身條件另算。

## 4. 水

### 4.1 水質六檔

| 水質 | 純度 | 價值修正 | 備註 |
|---|---|---:|---|
| 溝渠水 | < 90.00% | −90% | 劇毒，顏色可辨 |
| 鐵鏽水 | 90.00–95.99% | −75% | 危險，顏色可辨 |
| 幽靈水 | 96.00–97.99% | −33% | 肉眼近似優質水，農業／工業常用 |
| 基礎水 | 98.00–98.99% | 0 | 下層區標準用水 |
| 優質水 | 99.00–99.89% | +50% | 上層區標準用水 |
| 純水 | ≥ 99.90% | +100% | 醫院／實驗室等級 |

- 純度 = 水體積 ÷ 全部液體（含藥劑、酒精、雜質）。
- 新生成的水慣性偏低：幽靈水最常見 96.15%、均值 96.31%，九成落在 96.00–96.61%。
- 雜質分母是雜質總量。常規生成（純水／優質／幽靈）：有機 20%、微生物 15%、物理 10%、化學 30%、礦物 15%、重金屬 10%。

### 4.2 淨化手段

| 手段 | 去除 | 代價 | 上限 |
|---|---|---|---|
| 淨水藥片 | 先化學，再用剩餘藥效除微生物 | 消耗藥片；1 片夠一大瓶鐵鏽水 | 基礎～優質 |
| 濾水器（裝入水罐） | 雜質、微塑料、有機廢物 | 耐久 400，倒水時消耗 | 基礎～優質 |
| 淨水器（夜間通電） | 逐夜處理，雜質轉為水，總體積不變 | 容器＋供電＋模組 | 純水 |
| 海德拉微型淨水器 | 直接對容器使用 | 耐久 75，約 10 點／L | 基礎水 |
| 紫外線燈 | 微生物 | 一次性 | — |
| 水分收集器 | 夜間產水（基礎幽靈水） | 電力 | — |
| 蒸發器 | 餾出純水 | 需質量模組 | 純水 |
| 水培淨化作物 | 雜質（礦物質除外） | 佔作物耗水 | — |

- 藥片與濾水器互補：藥片走化學→微生物，濾水器管物理與有機。兩者併用多數水可到基礎水甚至優質水。
- 水商開局：試紙 10 張、藥片 9 片、濾水器耐久 400、微型淨水器耐久 75。

### 5.2 展示櫃買家

條件：吸引力 ≥ 100；正常開場第 1 天不來。基礎上限 1 名，展示櫃擴建 I／II 各 +1，買家推薦服務 +1。
品類按展示櫃內該品類**合計**預估價值取前 N 名，每品類來一位。

| 品類 | 高檔 | 中檔 | 低檔 |
|---|---|---|---|
| 水 | 囤水者（≥ 350，第 14 天起） | 星際客（≥ 145，或吸引力 ≥ 400） | 口渴的星際客、拾荒客 |
| 食物 | 上層區私人廚師（≥ 350） | 探險供應商（≥ 145） | 星際客、忍飢挨餓的星際客、星際客廚師 |
| 醫療 | 上層區醫院供貨商 | 中層區護士 | 負傷的星際客、病童看護者、下層區醫生 |
| 煙酒 | 上層區尋歡客 | 筋疲力盡的星際客 | 絕望的癮君子 |
| 材料／模組／工具 | 空間站工程師 | 下層區發明家 | 下層區修理工、廢品收購人、維護工人 |

- 水例外：展示櫃最貴的水是純水 → 第 14 天起必來高檔，之前至少中檔；是優質水 → 至少中檔。
- 模組／工具至少中檔；低科技品類永遠不來高檔。
- 實務：要水單就把幾瓶水一起擺，把品類合計堆到 145（中檔）或 350（高檔）。

| 條件 | 加成 |
|---|---:|
| 上層區聲望「好評如潮」 | +25% |
| 治安部聲望「可靠供應商」 | +50% |
| 特性馬屁精＋上層區顧客 | +10% |

| 吸引力 300／450／600／750／900 | +10／+25／+50／+75／+100% |

- 直接設定數值的顧客（如廢料客）不吃修正。
- 賣貨給「既買又賣」的顧客會讓他預算成長：一般 50%、面色慘白的拾荒客／農場主／傑克遜博士 100%、下層區化學家 125%。

### 5.4 生成順序（摘要）

展示櫃違禁盤查 → 重要劇情 → 王爾德援助 → 開局劇情 → 展示櫃買家 → 售後回饋／投訴 → 固定日程 → 事件顧客 → 開場引導（第 1–14 天）→ 常規盤查 → 補給運輸員（第 7 天首訪，之後每週日）→ 固定顧客 → 劇情 → 探險 → 情報販子 → 傑克遜博士 → 小人物 → 改造體 → 通緝犯 → 普通顧客 → 聲望特權 → 市場顧客 → 人脈服務 → 房東。

- 隨機顧客：正常開場第 14 天起；跳過開場第 2 天起。
- 通緝犯：每天 4% 起，每多隔一天 +2%，隔滿 16 天必來。
- 同一身份一天只來一位。

## 6. 交易

| 項目 | 規則 |
|---|---|
| 報價 | 以當前價格為準（第 3 節公式），之後才進議價 |
| 實收 | `min(單價, 剩餘預算)`，預算不足只付剩下的，差額不補 |
| 整批價 | `S − floor(S × d ÷ 100)`，d 為賣家整批折扣，可能固定或每次隨機 |
| 還價 | 可抬高售價或要求折扣，有成功率；失敗影響回饋 |
| 超預算成交 | 有聲望代價 |
| 櫃檯 | 前櫃檯擺不下的商品直接消失（beta 分支改為庫存頁，最多 12 頁） |
| 過夜 | 別把東西留在外面櫃檯，會失竊 |

先賣大件：預算是一次性扣減，小件先賣會吃掉大件的額度。

## 7. 驗貨

| 買家類型 | 能識破什麼 |
|---|---|
| 帶水質檢測試紙 | 任何水質虛標 |
| 只憑顏色 | 只能識破鐵鏽水／溝渠水冒充；幽靈水冒充純水看不出 |
| 遊客、上層區公民 | 通常不驗貨 |
| 大量購水者 | 通常自帶試劑盒 |

- 拾荒者與下層區公民通常不買優質水／純水。
- 香菸真偽、免疫寧（赝品／召回批次／過期）、化學純度各有買家表；召回批次是唯一所有買家都看不出的免疫寧問題。

| 犯罪值 | 每日證據 | 判決 |
|---|---:|---|
| 0–99 | 0 | 無 |
| 100–299 | +2 | 罰款 |
| 300–849 | +6 | 監禁 |
| 850–1199 | +9 | 監禁 |
| 1200–1499 | +12 | 監禁 |
| 1500–2499 | +20 | 處決 |
| ≥ 2500 | +33 | 處決 |

- 盤查：走私＋赃物 ≥ 50 才開始常規盤查；≥ 750 縮到 1–2 天一次；帶 VIP 不盤查。
- 赃物入帳按熱度 %，再乘買方陣營：黑市 ×1/2、革命軍 ×1/3、卡特尔 ×0、其他 ×1。

## 12. 議價

入口：交易平板右上角的對話氣泡。正常開場第 8 天由導師解鎖，跳過開場直接啟用；「不善議價」特性會停用；傑克遜的常規到店交易不開放。

| 檔位 | 折扣後價格 | 折扣後預算 | 加價後價格 | 加價後預算 |
|---|---:|---:|---:|---:|
| 10% | ×0.90 | +20% | ×1.10 | −10% |
| 25% | ×0.75 | +50% | ×1.25 | −15% |
| 50% | ×0.50 | +100% | ×1.50 | −20% |
| 75% | ×0.25 | +150% | ×1.75 | −25% |

- **同一顧客、同一方向只能議一次**，拒絕也算用掉；關掉面板不能重試。
- 打折加預算、抬價減預算；報價與預算分開算，最後仍按需求配貨。
- 議價與零售加成相乘，不相加：基礎 1000、普通難度 +15% → 1150，再折 50% → 575。

聲望（逐件、合法非贓物）：

```
聲望變化 = 議價前報價 × 交易倍率 × 派系係數 ÷ 400
```

| 派系 | 係數 | | 檔位 | 給優惠 | 要求讓利成功 |
|---|---:|---|---|---:|---:|
| 上層區 | 1.2 | | 10% | 1.65 | −0.5 |
| 下層區 | 0.66 | | 25% | 2.2 | −1.5 |
| 治安部／黑市／革命軍 | 1 | | 50% | 3 | −3 |
| 遊客 | 無聲望條 | | 75% | 3.9 | −5 |

- 難度倍率：輕鬆 ×1.5／×0.5、普通 ×1／×1、困難 ×0.75／×1.25、挑戰 ×0.5／×2；舌燦蓮花 ×1.33、馬屁精（上層區）×1.25。
- 顧客預算不足仍賣出：每件沒付足的貨，賣出倍率再 **+1**（少收錢但保聲望）。

| 要求幅度 | 接受 | 拒絕但留下 | 離開 |
|---|---:|---:|---:|
| 10% | 80% | 8% | 12% |
| 25% | 50% | 20% | 30% |
| 50% | 0% | 40% | 60% |
| 75% | 0% | 10% | 90% |

紅線：**敲詐勒索與威脅只能挑一個方向的一次機會**，失敗會掉派系聲望（−5～−10）；嘗試過就不能再舉報，威脅過也不能再掏霰彈槍。對普通人用是純虧。

## 14. 特性選配

- 基礎 **3 點、4 槽**；負面特性返點但仍佔槽；0 點特性也佔槽；點數可以不花完。
- 「奇人異士」1 點換 +3 槽（上限 7），本身也佔一格。
- 管道暢通給的是鐵鏽水，仍需設備與檢測——接通水管不會自動變成飲用水。
- 長線代價：高昂房租 +40、黃金地段 +75（之後漲租基數更高）；極簡／苦行者縮主背包；成癮是不定期的交易懲罰；告密者讓通緝客不再上門。

## 15. 機器與生產

| 主題 | 要點 |
|---|---|
| 3D 列印機 | 24 種晶片；備料＋電源＋模組，過夜取件；晶片清單見 reference |
| 電流轉換器 | 放進**機器電源槽**替換電池，不儲電；費率 1.5 → 1.0（電子元件升 5 次，每次 −0.1）；夜帳先把所有開啟的機器合計再整體向上取整，白天取電每次即時取整 |
| 偷接私電 | I／II／III 讓轉換器減費 15%／25%／50%，基礎費 300／600／1000，只取最高檔 |
| 修理 | 破舊 → 損壞 → 報廢三段；工具箱裝工具用數字鍵切換，廢金屬與電子元件是主要修理料 |
| 水培 | 種子＋水＋電，基因可編輯；淨化水質性狀的作物能順便濾水 |
| 釀酒 | 酵母＋糖源＋水，裝瓶後發酵；螢光莓果是進階原料 |
| 化學 | 夢塵等配方需化學台與前驅物，管制品要看違禁等級 |

## 16. 外出
