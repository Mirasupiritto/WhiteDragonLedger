# 新遊戲專精比較

這張表依《深空當鋪》0.46D 原版專精頁的順序整理。名稱與開局物資取自遊戲中文語系檔；可選狀態以一般完整版為準。遊戲每頁顯示 10 格，後兩項在第二頁。

| 專精 | MCP 選擇 ID | 可開局 | 開局物資、聲望與租金 |
|---|---|---|---|
| 學徒 | `apprentice` | 可 | 額外信用點、儲藏區、一批日用品與食物。遊戲推薦初次遊玩。 |
| 水商 | `water_merchant` | 可 | 水資源交易手冊、驗水與淨水設備、儲水容器。 |
| 銷贓人 | `fence` | 可 | 走私暗格、違禁品、清道夫地下交易所門路。黑市聲望較高、治安部聲望較低，起租較高。 |
| 一貧如洗 | `rock_bottom` | 可 | 沒有起始物資。遊戲標為極限挑戰。 |
| 水培農場主 | `hydroponic_farmer` | 可 | 水培農業手冊、水培系統、農用物資與種子。起租較高。 |
| 槍械匠 | `gunsmith` | 可 | I 級武器許可證、一批槍械與模組、彈藥。 |
| 化學家 | `chemist` | 可 | 化學手冊與實驗設備。 |
| 養鼠人 | `rancher` | 可 | 動物籠、老鼠與食物。 |
| 水產養殖戶 | `aquafarmer` | 可 | 循環水養殖系統、羅非魚與魚食。起租較高。 |
| 廢料客 | `junker` | 待開放 | 拾荒裝備與工具、熔爐，拾荒客初始聲望較高。 |
| 器官販子 | `organ_trader` | 待開放 | 器官交易手冊、冷藏容器與輸血設備。 |
| 街頭小吃攤販 | `street_food_vendor` | 待開放 | 烹飪手冊、爐灶與食材。 |

進到專精頁後，用 `get_specializations` 取得當次遊戲的完整表格，包括模組加入的可見專精、當前選中項目、原文描述、適合玩家的提示、初始擁有、是否略過教學與當下能否開局。沿用上次的 `view_token` 重查相同內容，只回 `unchanged`。

挑好後，把同一張回執的 `session`、`revision`、`view_token` 和選定的 `scenario_id` 交給 `choose_specialization`。遊戲會進入首輪提示或特性頁；進入特性頁後，可用 `starting_perks` 搭配[初始特性比較表](starting-perks.md)配點。
